# Maison Lin

A demo luxury boutique: browse a 3D clothing rail, turn each piece 360°, add it to the bag, and try it on live with your camera (AR, MediaPipe Pose + Three.js).

- `index.html`, `style.css`, `js/` — the site (no build step)
- `assets/*.glb` — rigged garments made in Blender (generated by script)
- `lib/` — vendored three.js and MediaPipe Tasks Vision

Run locally: `python3 -m http.server` and open http://localhost:8000 (camera needs localhost or https).

## Add a garment from two photos (AI shape)

```
python3 tools/ai_garment.py front.jpg back.jpg --type knit --name "Le Pull Onyx" --color "Cacao" --price 290
```

Hunyuan3D-2mv (Hugging Face) builds the real shape from both photos in seconds; Blender rigs it with the store's
skeleton; the photos are projected onto it and the sides get a seamless tile of the same fabric. ~30 s per piece.

### Older method: template projection

The site can turn a front and a back photo into a rigged 3D piece (rail, 360° view and AR all work with it):

```
python3 tools/add_garment.py front.jpg back.jpg --type hoodie --name "Le Hoodie Gris" --color "Gris" --price 240
```

or without a computer: upload a folder to `inbox/` on GitHub (see `inbox/README.md`) — a GitHub Action builds it.
The photos are cut out (rembg), de-lit, measured and projected onto the matching template (`hoodie`, `hoodie-pocket`, `knit`, `polo`);
results go to `assets/custom/` and appear in the shop, on the rail and in the fitting room.

## Fitting room (AR)

MediaPipe Pose drives the rigged garment; the multiclass selfie segmenter copies hair, face and hands from the camera
on top of the garment and measures the body so the piece is widened to cover the clothes underneath; the room itself
lights the fabric. The camera button saves or shares a photo of the look.

## Real store mode (Supabase + Stripe)

`js/config.js` empty → demo boutique. Filled → products, settings and orders come from Supabase and checkout goes
through Stripe. Owner panel: `/admin.html` (add pieces from two photos, edit/hide products, orders, texts, colours,
delivery, discount codes). Backend: `supabase/schema.sql`, edge functions in `supabase/functions/`
(`checkout`, `stripe-webhook`, `build-garment`), 3D build action `.github/workflows/build-garment.yml`.
Step-by-step setup (Arabic): `SETUP.md`.
