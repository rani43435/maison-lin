# Maison Lin

A demo luxury boutique: browse a 3D clothing rail, turn each piece 360°, add it to the bag, and try it on live with your camera (AR, MediaPipe Pose + Three.js).

- `index.html`, `style.css`, `js/` — the site (no build step)
- `assets/*.glb` — rigged garments made in Blender (generated by script)
- `lib/` — vendored three.js and MediaPipe Tasks Vision

Run locally: `python3 -m http.server` and open http://localhost:8000 (camera needs localhost or https).
