# Add a piece from two photos

Make a folder here (any name) with three files and push it — the site builds the 3D piece by itself:

- `front.jpg` — the whole garment from the front, plain background
- `back.jpg` — the same from the back, same distance
- `info.json` — `{"name": "Le Hoodie Gris", "color": "Gris", "price": 240, "type": "hoodie"}`

`type`: `hoodie`, `hoodie-pocket`, `knit` (crewneck / pullover) or `polo`.
